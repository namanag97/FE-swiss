## 4. Competitive Dynamics

### Celonis vs SAP Signavio — The Antitrust Battle
- **2021**: SAP acquired Signavio. Subsequently allegedly imposed technical barriers limiting third-party access to SAP ERP data, favoring Signavio.
- **March 2024**: Celonis filed complaint (N.D. California) — Sherman Antitrust Act + California Unfair Competition Law.
- **October 2025**: Court allowed most claims to proceed. Monopolization, attempted monopolization, illegal bundling/predatory pricing survive.
- **Trial date: December 7, 2026**. SAP agreed to allow Celonis data access until case resolved.
- **Stakes**: Tests whether dominant platform companies can erect barriers to customer data portability.

### Celonis vs Microsoft Power Automate
- **Threat level: Moderate, growing**. Microsoft is a Challenger in 2025 Gartner MQ.
- **Strength**: Built into Microsoft 365/Power Platform; nearly free for existing customers
- **Weakness**: Lacks depth for complex multi-system enterprise PM
- **Risk**: Democratizes basic PM, potentially commoditizing the low end

### Celonis vs UiPath — Coopetition
- UiPath is a Leader in 2025 Gartner MQ. Approach: automation-first (discover → deploy robots).
- Celonis approach: process-first (deepest discovery → connect to any automation).
- Many enterprises use **both**: Celonis for intelligence, UiPath for automation execution.

### Is PM Becoming a Feature?
**Yes — biggest strategic risk for standalone vendors.**

| Platform | How They Got PM |
|----------|----------------|
| SAP | Acquired Signavio (2021) |
| Microsoft | Acquired Minit (2022) |
| ServiceNow | Acquired UltimateSuite (2023); PM included by default |
| IBM | Acquired myInvenio |
| UiPath | Acquired ProcessGold |
| Pegasystems | Acquired EverFlow |

Enterprise vendors embedding PM as prerequisite for **agentic AI**. ServiceNow: "process mining insights are food for our AI agents." SAP: "If you want to deploy AI, you have to have process mining."

By 2026, **40% of enterprise apps** will include task-specific AI agents (Constellation Research). PM is the discovery/context layer feeding them.
